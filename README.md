Writing a good README every time is tedious. Fill in the form — name, tagline, description,
features, tech, license — and this generates clean, consistent markdown you can copy or download.

## ✨ Features

- **Form-driven** — type project details, markdown builds itself
- **Shield badges** — stars, last-commit, license, and a live-demo button
- **Optional sections** — table of contents, contributing, author footer; centered header toggle
- **Live preview** — switch between raw markdown and a rendered preview
- **Editable output** — tweak the generated markdown directly before copying
- **Copy** or **download** the finished `README.md`

## 🔒 Private by design

Everything runs **100% in your browser** — nothing is uploaded.

## 🧰 Tech

- **Vanilla HTML / CSS / JavaScript** — no frameworks, no dependencies, one `index.html`
- Includes a tiny built-in markdown renderer for the preview
- Hosted free on **GitHub Pages**

## ▶️ Run locally

```bash
start index.html      # Windows — no build step
```
